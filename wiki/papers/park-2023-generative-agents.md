# Generative Agents: Interactive Simulacra of Human Behavior

Joon Sung Park, Joseph C. O'Brien, Carrie J. Cai, Meredith Ringel Morris, Percy Liang, Michael S. Bernstein. Stanford / Google Research / Google DeepMind. UIST '23, October 2023. arXiv:2304.03442.

## Claim

An architecture combining a comprehensive memory stream (observations, reflections, plans), a retrieval function scoring memories by recency, importance, and relevance, and recursive hierarchical planning enables LLM-powered agents to produce believable individual and emergent social behavior over extended time horizons - without any additional training. (Abstract, §4)

## Method

Architecture has three interlocking components (§4, Fig. 5):

**Memory stream** - append-only log of all agent experiences as natural language entries, each with creation timestamp and last-access timestamp. Three entry types:
- *Observations*: events directly perceived by the agent (e.g., "Isabella is setting out pastries")
- *Reflections*: higher-level inferences synthesized from observations (e.g., "Klaus is dedicated to his research")
- *Plans*: future action sequences with location, start time, and duration

**Retrieval** (§4.1) - scores all memories and returns top-ranked subset for prompt context:
`score = α_recency·recency + α_importance·importance + α_relevance·relevance` (all α=1)
- Recency: exponential decay with factor 0.995 per sandbox hour since last access
- Importance: LLM asked to rate memory on 1-10 scale at creation time (breakfast ≈ 2, breakup ≈ 8)
- Relevance: cosine similarity of memory embedding to query embedding

**Reflection** (§4.2) - triggered when sum of recent importance scores > 150 (~2-3 times/day). Process: (1) identify 3 salient questions from 100 most recent memories, (2) retrieve relevant memories for each question, (3) LLM extracts insights with source citations. Results stored as new memory entries. Reflections can recursively synthesize other reflections (reflection tree, Fig. 7).

**Planning and reacting** (§4.3) - top-down recursive decomposition: rough day plan (5-8 chunks) → hour-long chunks → 5-15 minute actions. Plans stored in memory stream alongside observations and reflections. At each time step, agent perceives environment and decides whether to continue plan or react. Dialogue generated by conditioning on both agents' summarized relevant memories.

**Environment** (§5) - Smallville sandbox world represented as a tree (root → areas → subareas → objects). Each agent maintains a subgraph of known areas, updated as explored. Recursive tree traversal determines action locations. 25 unique agents with 1-paragraph seed descriptions. Implemented with ChatGPT (gpt-3.5-turbo).

## Boundary conditions

- **Cost**: 25 agents over 2 game days cost thousands of dollars in token credits and took multiple days to complete. Real-time interactivity not achieved (§8.2).
- **Memory retrieval failures**: agents forget events (fail to retrieve), retrieve incomplete fragments (Tom knows what he planned at the party but not that the party exists), and hallucinate embellishments to real memories (§6.5.2). Complete fabrication is rare; embellishment is common.
- **Location selection degrades with memory size**: as agents learn more locations, they choose less appropriate ones (agents going to a bar for lunch) - expanding memory set interferes with the retrieval function's ability to choose the most contextually appropriate location (§7.2).
- **Physical norms not representable in natural language**: constraints like "single-occupancy bathroom" or "store closes at 5pm" require explicit state annotations; agents violate implicit physical norms that natural language cannot convey (§7.2).
- **Instruction tuning artifacts**: overly formal dialogue (Mei addressing John formally), excessive cooperation (Isabella adopting interests she was not initialized with because she rarely says no) (§7.2, §3.1).
- **Short evaluation timescale**: 2-day simulation; long-term drift and error accumulation unknown (§8.2).
- **Robustness unknown**: vulnerable to prompt hacking, memory hacking (planting false memories via conversation), and hallucination; not tested (§8.2).
- **Bias inheritance**: agents inherit LLM biases and may underperform for marginalized populations (§8.2).
- **Crowdworker evaluation not expert baseline**: the human condition was not maximal expert performance (§6.2).

## Decision knowledge

| Design choice | Cue that motivated it | If absent | Newcomer trap |
|---|---|---|---|
| Three-component retrieval (recency + importance + relevance) | Each addresses a different failure mode: recency prevents forgetting recent events, importance surfaces poignant memories not just frequent ones, relevance surfaces contextually appropriate memories (§4.1) | Any one omitted: agents forget recent events (no recency), treat breakups and breakfast equally (no importance), or retrieve by frequency not context (no relevance) | Assuming relevance alone suffices; it does not capture that a painful memory matters even if rarely accessed |
| LLM-rated importance score at creation time (not retrieval time) | Importance is stable for a memory object and expensive to recompute; tagging at creation is O(1) per memory vs O(memories) per retrieval (§4.1) | Recomputation at retrieval time is not proposed; absence would mean treating all memories as equally salient | [not stated in source]: the 1-10 scale and prompt wording were chosen without ablation |
| Reflection triggered by importance threshold (>150), not time | Time-based triggers would generate reflections at arbitrary moments; importance threshold ensures reflections occur when enough significant events have accumulated to be worth synthesizing (§4.2) | Time-based: reflections happen on an arbitrary schedule regardless of event significance | The threshold 150 is not ablated; assumed to be empirically tuned |
| Recursive top-down planning | Directly generating 5-minute actions produces incoherent day-level behavior (eating lunch three times); top-down provides global constraints before local detail (§4.3) | Without planning: agent optimizes believability moment-to-moment but not across time | Planning alone is insufficient; without memory retrieval, plans ignore past experience |
| All memories stored as natural language, not structured representations | Allows the architecture to leverage LLM's language understanding throughout; structured representations would require additional translation layers (§4) | Structured: faster lookup but loses LLM's ability to reason flexibly over memory content | [not stated in source]: performance of structured memory alternatives not studied |

## Not stated in source

- The importance threshold (150) and recency decay factor (0.995) are not ablated; optimal values unknown.
- The weights α=1 for all three retrieval components are not ablated. Optimal weighting unknown.
- No cost-accuracy tradeoff analysis: how much cheaper a sparser simulation (fewer agents, shorter memory) would be while retaining emergent behaviors.
- The reflection tree depth is not bounded explicitly; how deep reflections compound across days is unknown.
- No comparison to simpler agent architectures at equivalent inference cost (the baseline has no memory, not a cheaper memory).
- User manipulation of agents via "inner voice" (§3.1.2) could systematically alter agent behavior; this is not evaluated as a robustness concern.
